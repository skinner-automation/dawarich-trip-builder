# Dawarich Trip Builder

A companion application for Dawarich that allows historical trips to be recreated without GPS data.

## Planned Features

- Interactive map
- Photon geocoding
- GPX generation
- KML export
- Direct Dawarich integration
- Trip timeline editor
- Local routing support (OSRM)

## Current Status

✅ FastAPI running in Docker

Version: 0.1.0
